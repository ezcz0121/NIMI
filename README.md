# NIMI
Nimble Inventory Management Interface. This program was designed to support a small business's inventory tracking, management, and fulfilment. Often within the convention, market, and pop-up shop scene it's easy to get lost on what's needed and what's actually in demand. NIMI is designed to work with Mobile and Desktop infrastructure.
